# Tanger Star Voice 🌟

A modern social voice-chat platform designed to connect people, create rooms, play games, and make new friends.

## 🚀 Features

- 🎙️ Voice chat rooms
- 👥 Social profiles and followers
- 💬 Real-time messaging
- 🎁 Virtual gifts and coins
- 🌍 Global community
- 🎮 Interactive games
- 🔔 Notifications
- 👤 User profiles and VIP features

## 🛠️ Technology

- Android
- JavaScript
- HTML & CSS
- Backend & Database
- Real-time services

## 📱 Project

Tanger Star Voice is being developed as a global social communication platform with a modern mobile-first experience.
